Sobre "acertar em todos os jogos": nenhum modelo matemático torna o futebol previsível a 100% — é um desporto com poucos golos e forte acaso (lesões, arbitragem, sorte). Esta ferramenta usa dados reais + Poisson + Monte Carlo + um algoritmo genético para maximizar a tua probabilidade de acerto dentro de um orçamento, nunca para a garantir. Trata os resultados como apoio à decisão, não como certezas.

📐 Como funciona o modelo (em português simples)

Clica para ver o método passo a passo
  1. Médias reais da equipa: quantos golos marca/sofre por jogo, calculadas separadamente para quando joga em casa e quando joga fora (não misturadas), e dando mais peso aos jogos mais recentes.
  2. Confronto direto (H2H): se as duas equipas já se cruzaram no histórico registado, isso entra na conta com mais peso quanto mais jogos houver entre elas.
  3. Golos esperados (λ): cruza o ataque de uma equipa com a defesa da outra, mais uma pequena vantagem por jogar em casa.
  4. Distribuição de Poisson: os golos no futebol seguem aproximadamente esta distribuição estatística — dá a probabilidade de cada resultado exato (0-0, 1-0, 2-1, etc.).
  5. Correção Dixon-Coles: o Poisson simples subestima ligeiramente os resultados baixos (0-0, 1-0, 0-1, 1-1) — aplicamos a correção clássica desta área (Dixon & Coles, 1997) para compensar isso.
  6. Monte Carlo: em vez de só calcular, "joga-se" o confronto milhares de vezes ao computador para confirmar que os números batem certo e mostrar a margem de erro estatística real.
  7. Algoritmo genético: quando queres uma aposta múltipla, evolui centenas de combinações de duplas/triplas e escolhe a que maximiza, segundo este modelo, a tua probabilidade de acertar 12 ou mais jogos dentro do orçamento que definires.

Isto é o mesmo tipo de método usado em estudos públicos de modelação de futebol (ex.: análises da Premier League com dados completos de uma época): sem esses dados reais preenchidos aqui, o modelo cai para médias genéricas da liga, sempre marcadas com ⚠️ para não pareceres estar a ver um dado real quando é só uma estimativa.

🧬 Algoritmo genético — otimizar múltiplas

Evolui uma população de sistemas de duplas/triplas (seleção por torneio, cruzamento, mutação, elitismo + imigrantes aleatórios a cada geração para não estagnar) e escolhe o que maximiza — por Monte Carlo — a probabilidade real de 12+ acertos dentro da combinação oficial escolhida. Usa também forma recente ponderada (jogos mais recentes pesam mais) e histórico direto entre as duas equipas (H2H), quando existir. Não é magia: reorganiza melhor a tua aposta com a informação real que já tens — não garante acertos.

Nota honesta: não existe "ligação a supercomputadores mundiais" real que eu possa oferecer aqui — isso não é uma funcionalidade que exista para um ficheiro HTML autónomo. O que existe de real e útil são as 3 APIs gratuitas de futebol (separador 🔌 APIs/Sync) e este motor a correr localmente no teu browser, que já é rápido o suficiente para milhares de simulações em segundos.
